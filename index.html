Database Cloud Firebase (Firestore)

Sinkronisasi data tautan otomatis ke seluruh perangkat secara realtime

Mode Penyimpanan Lokal (Offline)

Tautan tersimpan di browser perangkat ini. Hubungkan Firebase agar tersinkronisasi online ke semua pengunjung.

Panduan Cepat Firebase Firestore (100% Gratis dari Google):

  1. Buka console.firebase.google.com dan klik Tambah Proyek (Beri nama bebas, misal: nexuslink-db).
  2. Di menu samping, pilih Build ➔ Firestore Database ➔ Create database (Pilih mode Start in test mode).
  3. Di tab Rules Firestore, pastikan tertulis allow read, write: if true; lalu klik Publish agar dapat dibaca/ditulis tanpa batasan 30 hari.
  4. Buka Project settings (Ikon Gerigi ⚙️) ➔ di bagian Your apps, klik ikon web </> (Web App).
  5. Salin seluruh kode objek const firebaseConfig = { ... } lalu tempel pada kotak di bawah ini.
Anda bisa langsung menempel kode lengkap dari Firebase Console di atas.
